# Octarine — кофейня восьмого цвета

Учебный проект: сайт кофейни с каталогом, корзиной, оформлением заказов, генерацией чеков, личным кабинетом, админкой, аналитикой и drag-and-drop системой стикеров.

Стек: React 19, Vite 8, TypeScript, Tailwind CSS v4. Бэкенд на Express (`server/`) подключается опционально: без него данные хранятся в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Приложение открывается на `http://localhost:8443`. В Figma Make можно использовать уже запущенную панель предпросмотра.

Чтобы включить API:

```bash
npm run server
```

Бэкенд поднимается на `http://localhost:4545`, Vite проксирует запросы `/api` на него. Проверка: `http://localhost:4545/api/health`.

Демо-администратор:

- Email: `admin@octarine.ru`
- Пароль: `admin123`

Навигация по разделам находится в чёрной панели внизу экрана: «Главная», «Каталог», «Блог», «Корзина», «Войти». После входа администратора появляется кнопка «Админка».

## Проверка: генерация чеков

1. В нижней панели откройте «Каталог», добавьте несколько товаров в корзину.
2. Откройте «Корзина» → «Оформить заказ».
3. Заполните имя и телефон, при желании email и комментарий, выберите способ оплаты (`Карта`, `Наличные` или `На стойке`) и нажмите «Подтвердить заказ →».
4. Сразу откроется страница заказа с готовым чеком: номер чека, дата, клиент, позиции, количество, суммы, итог и способ оплаты.
5. Кнопка «Печать чека» открывает системную печать (`window.print()`), кнопка «Скачать .txt» сохраняет файл `octarine-check-<номер>.txt`.
6. Готовый пример чека без оформления заказа: `http://localhost:8443/#/order/ord_demo_1`.
7. В админке чек можно проверить в разделе «Заказы» — там же видны номер чека и сумма заказа.

Код чека: `src/pages.tsx` (`ReceiptPage`), формирование заказа — `src/store.tsx` (`checkout`).

## Проверка: drag-and-drop система стикеров

1. В нижней панели нажмите «Войти» и введите `admin@octarine.ru` / `admin123`.
2. Откройте «Админка» → вкладка «Стикеры». Прямая ссылка: `http://localhost:8443/#/admin/stickers`.
3. Слева находится палитра символов. Перетащите значок на макет справа — стикер появится в точке отпускания. Клик по значку палитры добавляет стикер в центр макета.
4. Нажмите на стикер на макете, чтобы выбрать его. Выбранный стикер можно двигать мышью или касанием (pointer events).
5. В настройках выбранного стикера доступны цвет, размер (24–96 px), поворот (-45°…45°) и кнопка «Удалить стикер».
6. Галочка «Показывать стикеры на главной» включает вывод стикеров поверх hero-блока главной страницы. По умолчанию галочка выключена, чтобы сохранить исходный дизайн; состояние сохраняется в `localStorage`.

Код системы стикеров: `src/admin.tsx` (`StickersAdmin`), состояние — `src/store.tsx`, вывод на главной — `src/landing.tsx`. Ключи `localStorage`: `octarine.v1.stickers` и `octarine.v1.showStickersOnLanding`.

## Остальные возможности

- Каталог: поиск, фильтры по категориям, сортировка.
- Корзина: изменение количества, удаление, подсчёт суммы, оформление заказа.
- Блог: список статей и страницы статей.
- Личный кабинет: история заказов и чеков.
- Админка: сводка, товары, контент, заказы, аналитика (KPI, столбчатая и круговая диаграммы, таблица продаж), стикеры.

## Структура

```text
src/
  App.tsx      — роутинг и оболочка приложения
  landing.tsx  — главная страница
  pages.tsx    — каталог, корзина, чек, блог, вход, аккаунт
  admin.tsx    — админка, аналитика и редактор стикеров
  store.tsx    — состояние, localStorage и API
  data.ts      — демо-данные и типы
  index.css    — базовые стили и стили лендинга
  app.css      — стили приложения и страниц
server/
  index.js     — API (health, products, posts, orders, auth, admin)
  db.js        — локальное хранилище API
```
