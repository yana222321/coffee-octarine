# Отчет по проекту «Octarine — кофейня восьмого цвета»

## 1. Цель работы

Создать полнофункциональный сайт кофейни на основе исходного макета, сохранить его визуальный стиль и добавить функциональность, обязательную по ТЗ: генерацию чеков и drag-and-drop систему стикеров. Сайт должен выглядеть как готовый продукт, а не как статичный макет.

## 2. Выполненные работы

### 2.1. Основной сайт

- Главная страница сохранена в исходной композиции: ширина 1160 px, рамка, чёрный фон вокруг. Вместо верхней шапки, которая смещала макет, добавлена компактная навигационная панель внизу экрана.
- Реализованы разделы: «Главная», «Каталог», «Блог», «Корзина», «Войти», «Личный кабинет», «Админка».
- Каталог поддерживает поиск, фильтрацию по категориям и сортировку.
- Корзина позволяет менять количество товаров, удалять позиции, считать итоговую сумму и оформлять заказ.
- Добавлены страницы статей блога и история заказов в личном кабинете.

### 2.2. Генерация чеков

- После подтверждения заказа автоматически создаётся чек с уникальным номером, датой, данными клиента, списком позиций, количеством, суммой, итогом и способом оплаты.
- Чек отображается на отдельной странице заказа.
- Доступны кнопки «Печать чека» и «Скачать .txt». Файл имеет имя вида `octarine-check-<номер>.txt`.
- Для печати используется отдельное CSS-правило: в печатаемой версии скрываются элементы интерфейса и остаётся только чек.
- Готовый пример чека доступен по адресу `http://localhost:8443/#/order/ord_demo_1`.

Код реализации: `src/pages.tsx` (`ReceiptPage`), `src/store.tsx` (`checkout`).

### 2.3. Drag-and-drop система стикеров

- В админке есть вкладка «Стикеры» с палитрой символов и макетом главной страницы.
- Стикер добавляется перетаскиванием из палитры на макет; клик по значку палитры добавляет стикер в центр.
- Стикеры перемещаются мышью и касанием через pointer events.
- Для выбранного стикера доступны настройки цвета, размера и поворота, а также удаление.
- Галочка «Показывать стикеры на главной» включает вывод стикеров поверх hero-блока. По умолчанию она выключена, чтобы не менять утверждённый вид главной страницы.
- Состояние стикеров сохраняется в `localStorage` (`octarine.v1.stickers`, `octarine.v1.showStickersOnLanding`).

Код реализации: `src/admin.tsx` (`StickersAdmin`), `src/store.tsx`, `src/landing.tsx`. Прямая ссылка на редактор: `http://localhost:8443/#/admin/stickers`.

### 2.4. Админка и аналитика

- Разделы админки: сводка, товары, контент, заказы, аналитика, стикеры.
- Реализованы CRUD-операции для товаров и статей, изменение статусов заказов.
- Аналитика включает KPI-показатели, столбчатую диаграмму, круговую диаграмму и таблицу продаж по товарам.

### 2.5. Бэкенд

- Добавлен Express API: здоровье сервера, товары, статьи, заказы, регистрация, вход, административные методы и статистика.
- API является опциональным: при недоступности сервера приложение работает на локальных данных в `localStorage`.

## 3. Технический стек

- React 19, TypeScript 5.7, Vite 8.
- Tailwind CSS v4, собственные стили в `src/index.css` и `src/app.css`.
- Express 4 для серверной части.
- Git, GitHub, Git LFS для изображений.

## 4. Структура проекта

```text
src/
  App.tsx      — роутинг и оболочка приложения
  landing.tsx  — главная страница
  pages.tsx    — каталог, корзина, чек, блог, вход, аккаунт
  admin.tsx    — админка, аналитика и редактор стикеров
  store.tsx    — состояние, localStorage и запросы к API
  data.ts      — демо-данные и типы
server/
  index.js     — API
  db.js        — локальное хранилище API
README.md      — инструкция по запуску и проверке
```

## 5. Запуск и демонстрация

- Запуск фронтенда: `npm run dev`, адрес `http://localhost:8443`.
- Запуск API: `npm run server`, адрес `http://localhost:4545`.
- Демо-администратор: `admin@octarine.ru` / `admin123`.
- Проверка чека: оформить заказ через корзину или открыть `#/order/ord_demo_1`.
- Проверка стикеров: войти как администратор, открыть «Админка» → «Стикеры» или `#/admin/stickers`.

Подробная пошаговая инструкция находится в `README.md`.

## 6. Результат

Все запланированные функции реализованы и работают. Проект проходит сборку и проверку типов, запускается локально и размещён в GitHub-репозитории `yana222321/coffee-octarine`. Внешний вид главной страницы сохранён в соответствии с исходным макетом, а обязательные элементы ТЗ — генерация чеков и drag-and-drop стикеры — доступны через интерфейс сайта.

## 7. Заключение

Проект представляет собой готовый сайт кофейни с административной панелью и интерактивными функциями. Реализация позволяет продемонстрировать как пользовательские сценарии (выбор товаров, заказ, получение чека), так и административные (управление контентом, аналитика, работа со стикерами).
